# Задачі реалізації Cost для Pull Requests

[Специфікація](../server/specs/pull-request-review-cost.md) · [План реалізації](plan.md)

- [x] **T1. Перевірити повноту вартості агента** · `reviewer-core`, `server` · незалежна задача. Додати вузькі перевірки адаптерів на відомий нуль, відсутність usage і кілька спроб зі змішаним джерелом ціни. Перевірити, що кілька частин рев’ю з однією невідомою ціною дають невідому повну суму. Критерії AC-04, AC-06. Перевірка — `npm test` у `reviewer-core` і серверні тести адаптерів без БД.
- [x] **T2. Зберегти запуск, його групу та вартість** · `server` · після T1. Додати міграцію для суми, зв’язку з групою й моменту фіналізації. Створювати групу й агентські запуски атомарно. Зберегти повну відому ціну навіть при подальшому збої, підтримати скасування та завершення осиротілих записів. Критерії AC-01, AC-05, AC-06. Перевірка — міграція з попереднього стану та `server/test/reviews.it.test.ts` із моками моделей.
- [x] **T3. Показати ціну в Timeline і Trace** · `server`, `client` · після T2. Додати поля у дві копії контрактів, віддавати ту саму суму в історії й трасі, обмежити читання трасування робочим простором. Додати підписи, спільний форматер і картку `Cost`. Критерії AC-02, AC-03, AC-04, AC-08, AC-09. Перевірка — server integration для ізоляції та `RunHistory.test.tsx` і `RunTraceDrawer.test.tsx` для значень і старих відповідей.
- [x] **T4. Показати Cost останньої команди у списку PR** · `server`, `client` · після T2 і T3 для спільного форматера. Додати пакетне отримання останніх завершених груп, поля суми й повноти, колонку та позначку `Partial`. Критерії AC-01, AC-04, AC-05, AC-07, AC-08, AC-09. Перевірка — серверний list integration із двома командами, завершеними в різному порядку, активною групою, видаленням і всіма станами вартості. Компонентний тест прив’язує колонку до правильного рядка.
- [x] **T5. Звести оновлення трьох екранів** · `client` · після T3 і T4. Підключити оновлення після фіналізації й видалення та очікування фіналізації після запиту на скасування. Критерії AC-06, AC-07. Перевірка — сценарій зі скасуванням під час модельного виклику та відкритим Trace, далі повернення до списку без перезавантаження.
- [x] **T6. Перевірити сценарій у браузері** · `server`, `e2e` · після T5. Підготувати стабільний seed для Pull Requests → Agent runs → Trace й перевірити вузьку верстку. Перевірка — `npm run e2e:hermetic` у `e2e`, `pnpm typecheck` і пакетні тести в `client` та `server`, `npm run typecheck` і `npm test` у `reviewer-core`.
